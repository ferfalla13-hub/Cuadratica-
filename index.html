¿Qué es? Fórmula Discriminante Calculadora

¿Qué es una ecuación cuadrática?

Es una ecuación de segundo grado cuya forma general es:

ax² + bx + c = 0

Donde:

  • a = coeficiente cuadrático
  • b = coeficiente lineal
  • c = término independiente

La Fórmula General

x = (-b ± √(b² - 4ac)) / 2a

a: coeficiente cuadrático.

b: coeficiente lineal.

c: término independiente.

El Discriminante

El discriminante es:

D = b² - 4ac

Valor Resultado
D > 0 Dos soluciones reales.
D = 0 Una solución real.
D < 0 Dos soluciones complejas.

Ejemplo

x² -5x +6=0

Resultado: x₁=3 x₂=2
